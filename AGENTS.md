## Continuity

Read `HANDOFF.md` for current state, blockers, verification, and the next action.
Use [PLAN.md](PLAN.md#open-work-and-decisions) as this project's authoritative
backlog and [CHANGELOG.md](CHANGELOG.md) for completed-change history.
Follow these routes when the records exist; meditation creates missing
continuity records only when authorized and consistent with project conventions.

Keep this file a stable quick start. Handoff is not a changelog or a duplicate
backlog. Preserve history before pruning active records, and keep unresolved
tasks until evidence or an explicit decision closes them. Meditation recommends
skills or automation for demonstrated needs; authoring, broader adoption, and
Mall submission require separate approval. It does not write episodic or native
memory. Existing episodes are historical evidence, not active guidance.
Cross-project work stays explicit until separately authorized.

## Project artifact storage

Keep requested documents, plans, reports, code, useful one-off helpers,
generated outputs, and required supporting evidence inside this repository,
never solely in session or temporary storage. Respect approved destinations
and existing project ownership. Before completion, verify final files,
dependencies, links, Git ignore state, and actual Git state.
Preserve originals and frozen evidence. Exclude credentials, runtime state,
raw personal data, and unapproved cross-project material. This storage rule
grants no execution, installation, commit, push, or publication authority
and is not a host-enforced filesystem boundary.

The [historical recovery index](docs/session-artifact-recovery/2026-11-08/README.md)
preserves the session assessment and backup receipt, not current verification.
